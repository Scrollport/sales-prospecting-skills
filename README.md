# Sales and prospecting Skills

Agent Skills for turning an ideal-customer profile into evidence-backed accounts
and verified professional contacts, powered by
[Scrollport](https://scrollport.com).

## Start with the job

| If you need to... | Use |
| --- | --- |
| Choose a verified sales-research workflow | [`sales-prospecting`](skills/sales-prospecting/SKILL.md) |
| Build a ranked account-and-contact list for human review | [`sales-qualified-accounts`](skills/sales-qualified-accounts/SKILL.md) |
| Research and then update an existing CRM contact | `sales-prospecting-to-crm` is a draft candidate and is not installable |

This category is intentionally narrower than GTM. It covers account research,
contact discovery and verification; it does not claim positioning, pricing,
campaign orchestration, forecasting, attribution or revenue operations.

## Safety and evidence

- Company fit and current-role claims retain public evidence.
- Work emails are verified without inferring private addresses.
- Research never authorises outreach or CRM mutation.
- Every paid expansion has a caller-approved count and spend ceiling.

## Install and contribute

Choose one function Skill or install the router first; see
[INSTALL.md](INSTALL.md) for pinned installation and readiness checks.
Published Skills live under `skills/`, while unverified work stays under
`candidates/`. See [the authoring contract](docs/AUTHORING.md),
[contribution guide](CONTRIBUTING.md) and [security policy](SECURITY.md).
